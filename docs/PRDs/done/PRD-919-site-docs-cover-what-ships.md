# PRD-919 — The site docs say what ships: fix 18 wrong statements, add 20 missing topics, derive the site counts

**Status:** DONE — all three phases and all six acceptance criteria verified, the last one on the live site.
**Priority:** P2 — AC-1 to AC-6 are open. A visitor who follows the public guides hits a template that does not exist, a Blender MCP server that is not wired, and a WebGL2 fallback that the default engine does not have. Whole shipped systems (spells, particles, GI, networking, navigation, deploy) have no guide.
**Complexity:** 4 (MEDIUM) — about 25 Markdown files in the engine repo and 8 content files in the private site repo; one new drift test; no runtime code.
**Owner:** João
**Depends on:** None

## Context

The site docs are not written on the site. `threenative-site/scripts/guides-plugin.ts` builds every docs page from `docs/guides/*.md` in this repo. It builds the API explorer from `packages/core/capabilities.json`. It builds the Recipes from `packages/create-threenative/agent-docs/references/*.md`, except every `kit-*.md` (`guides-plugin.ts:182`). It builds package pages from each package README. The claim and comparison pages are hand-written in `threenative-site/src/content/*.ts`.

On 2026-11-25 four read-only scouts (leanpi, DeepSeek V4.1 Flash max) compared what ships on `develop` with what those sources say. Three scouts found the same gaps on their own (the `defense` template, the Blender server, the stale counts, navigation), so those are high confidence. The lead opened the cited line for every high-severity finding below and confirmed it. Items marked "verify" were not opened yet.

Scout raw output is not stored. The finding list below is the record.

## Solution

Three phases, in order of harm. Phase 1 corrects statements that are false today. Phase 2 adds the missing guides and sections. Phase 3 fixes the hand-written site claims and adds a drift test, so the next gap fails a check instead of waiting for a scout.

Keep each fix at the source: edit `docs/guides/*.md`, a package README or a recipe, never the site copy. The site picks it up on its next build.
