# Credits

## Audio

Every clip in `assets/` is **generated by this project's own tool**, `tools/make-racing-audio.mjs`,
from the maths in that file. They are original works of this repository under its MIT licence —
there is no third-party recording in them, and nothing to attribute.

| File | Made by | Licence | Source |
| --- | --- | --- | --- |
| `assets/engine-loop.wav` | `node tools/make-racing-audio.mjs` | MIT (this repository) | none — synthesised |
| `assets/tyre-squeal.wav` | `node tools/make-racing-audio.mjs` | MIT (this repository) | none — synthesised |
| `assets/nitro-burst.wav` | `node tools/make-racing-audio.mjs` | MIT (this repository) | none — synthesised |

Why not a downloaded clip: the audio catalogue the asset tools reach was searched for an engine, a
tyre and a boost (`audio_search_assets`). It returns seven items — two Kenney packs, "Interface
Sounds" and "Music Jingles", both CC0, and the five Sonniss GDC 2026 bundles, whose stated licence
is the "Sonniss GDC Game Audio Bundle License" and whose download is one multi-gigabyte archive per
part. None of them is an engine bed, a tyre squeal or a nitro burst.

An engine bed also cannot be a recording here, for a second reason: it is pitched live from 0.62×
to 2.05× (`src/audio/engine.ts`), so the loop has to be tonal and exactly periodic, and a recording
of a real engine is neither. `tools/make-racing-audio.mjs` builds the seam in — every frequency is a
whole number of cycles per loop — and the bake proves it before it writes a byte.

Swap any file for a recording without touching the game: the paths are named in `ENGINE_SOUND.clips`
and the levels in the same object. If you do, add the recording's source, licence and URL to this
file, and keep `loop: true` for the two beds in `threenative.config.ts` so the audio pass keeps
checking the join.
